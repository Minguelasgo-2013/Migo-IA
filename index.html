El proyecto

Construyendo una inteligencia artificial propia.

🧠 Modelo propio

Arquitectura experimental de tipo Transformer desarrollada con PyTorch.

⚡ Entrenamiento

Experimentación con datos, vocabulario, parámetros y procesos de entrenamiento.

💬 Conversación

Desarrollo de herramientas para interactuar con el modelo mediante texto.

Tecnología

Migo IA utiliza Python y PyTorch como base tecnológica. El proyecto explora modelos de lenguaje, tokenización, redes neuronales y aprendizaje automático. Su desarrollo continúa evolucionando.
